# 实时金价 Chrome 扩展

点击工具栏图标，实时查看国际现货贵金属、上海金交所行情、品牌金饰与银行金条价格。

- **当前版本**：v1.2.0（见 `manifest.json`）
- **运行环境**：Chrome / Edge 等 Chromium 内核浏览器（Manifest V3）

## 功能特性

- **顶部双卡片**
  - 国际现货金 XAU（美元/盎司，按美元汇率折算 ≈ 元/克）
  - 沪金 Au99.99（元/克）
  - 各附最近约 6 小时迷你走势图
- **国际现货**（美元/盎司）：现货黄金、现货白银、现货铂金、现货钯金 —— 卖出/买入双价 + 当日高/低
- **上海金交所**（元/克）：黄金9999、黄金T+D、白银T+D（元/千克）、铂金9995、m黄金T+D、黄金9995、金条100g
- **品牌金饰价**（元/克）：周大福、老凤祥、周六福、周生生、六福珠宝、梦金园、老庙、金至尊、菜百、周大生、潮宏基 —— 价格/涨跌/更新时间
- **银行金条价**（元/克）：建行、中行、工行、农行、平安、浦发、邮储、交行、民生、招行、中信、兴业 —— 银行名 + 产品名 + 价格/涨跌/更新时间
- **自动刷新**：后台 Service Worker 每分钟轮询；打开弹窗时数据超过 60 秒未更新会自动补拉
- **限流兜底**：金投接口被限流（HTTP 666）时自动退避 5 分钟，并切换新浪行情兜底金交所品种

## 安装

1. Chrome 地址栏打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `gold-price-extension`
4. 建议把图标固定（Pin）到工具栏，方便随时查看

## 使用说明

- **查看行情**：点击工具栏图标弹出面板，分四个区块展示行情
- **手动刷新**：点击弹窗右上角 ⟳ 按钮
- **数据时效**：顶部显示最近更新时间；后台每分钟自动轮询，无需保持弹窗打开

## 数据来源

| 数据 | 接口 | 说明 |
|---|---|---|
| 美元汇率、国际金兜底 | 腾讯 `qt.gtimg.cn` | 免 Referer，GBK 编码 |
| 国际现货 / 金交所 / 品牌 / 银行金条 | 金投 `api.jijinhao.com` | 需 Referer，由扩展 DNR 规则注入 |
| 金交所品种（兜底） | 新浪 `hq.sinajs.cn` | 金投限流时自动切换 |

## 工作原理

- **轮询**：`chrome.alarms` 每 1 分钟唤醒 Service Worker 拉取行情，结果写入 `chrome.storage.local`
- **Referer 注入**：金投/新浪接口校验 Referer，通过 `declarativeNetRequest` 动态规则注入，并用 `initiatorDomains` 限制为仅对本扩展自身发起的请求生效
- **历史曲线**：每次刷新把最新价追加到 `history`，每品种最多保留 360 个点（约 6 小时），弹窗内用 SVG 绘制迷你走势图
- **退避策略**：金投返回 HTTP 666（限流）后，5 分钟内不再请求金投，改走新浪兜底；退避期间非覆盖品种（银/铂/钯、品牌、银行）显示上次缓存数据

## 文件结构

```
├── manifest.json      # MV3 清单：权限、host_permissions、action
├── background.js      # Service Worker：轮询、三源解析、历史存储、DNR 规则
├── popup.html         # 弹窗布局：双卡片 + 四个行情区块
├── popup.css          # 弹窗样式
├── popup.js           # 弹窗渲染：行情行、走势图、手动刷新
└── icons/             # 16/32/48/128 图标 + 源 SVG
```

## 权限说明

| 权限 | 用途 |
|---|---|
| `alarms` | 每分钟定时唤醒后台拉取行情 |
| `storage` | 缓存行情与历史数据 |
| `declarativeNetRequestWithHostAccess` | 注入金投/新浪接口要求的 Referer 头 |

扩展不收集任何用户数据，不访问页面内容，所有请求均为公开行情接口。

## 常见问题

- **品牌/银行金饰价不更新？** 品牌金饰价本身每天只变一两次，并非高频行情，属正常现象。
- **部分数据长时间不变？** 可能触发了金投限流，退避期内显示上次缓存，5 分钟后自动恢复。
- **弹窗显示"暂无数据"？** 首次安装需等首次拉取完成（数秒内）；若持续无数据，可在扩展详情页查看 Service Worker 日志。

## 注意事项

- 行情数据来源于第三方公开接口，仅供参考，不构成投资建议
- 金投字段：`q63` 最新价、`q5/q6` 买/卖价、`q3/q4` 高/低、`q1/q2` 开/昨结、`q70/q80` 涨跌/涨跌幅
